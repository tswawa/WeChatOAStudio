# 发布前审查

版本：0.3.14。项目代码许可：GPL-3.0-only。

## 隐私与文件范围

源码通过白名单从开发目录整理，包含应用代码、测试、构建资源、文档和演示截图。账号数据库、浏览器会话、模型设置、发表回执、聊天、文章配图、附件、日志、现场截图、调试脚本和历史构建均排除。

采用 Gitleaks 8.30.1 进行源码和解包代码扫描。同时在本机内存中读取当前已配置模型密钥和账号标识，对源码、Windows 包目录及安装器解包内容逐字节比对；报告仅保留命中数量与检查类型。

构建检查发现 SQLite 原生依赖携带编译工程和本机路径记录，已通过打包排除规则剔除并重新构建。最终精确比对未发现已配置密钥、真实账号标识、本机路径或用户数据文件。

## 构建与测试

- 在独立构建目录使用 `npm ci` 安装锁定依赖。
- 386 项自动测试通过，前端和 Windows 安装器构建通过。
- 首轮并行测试中一个长工具循环用例达到测试时限；该用例单独复测通过，随后完整测试集重跑全部通过。增加默认规则检查时，修正了受控测试服务在 UTF-8 网络分块边界的解码方式，长中文资料的完整性测试通过。
- 新安装加载自动配图、短文配图、原始资讯来源及内容优先取图规则；桌面与定时任务均传入模型上下文，后续作者编辑仍保留。
- 应用归档排除测试文件，安装器的应用负载与检查过的打包目录核对一致。
- GPL、第三方许可和 Electron/Chromium 通知文件随包分发。

## 首次启动

使用打包后的主进程代码与包内依赖，在隔离的 Electron 数据目录启动检查：

- 账号、聊天、会话、任务、模板、记忆、配图与附件记录均为 0。
- 默认模型名与模型密钥为空，公众号开发凭据文件不存在；身份规则与公开源码默认值逐字一致。
- SQLite 原生模块、sharp 图片解码、PDF 子进程解析和 DOCX 模块加载通过。
- 检查过程阻止外部网络请求，真实公众号写入为 0。

README 中的 DeepSeek bot 文稿与配图沿用作者指定的创作案例，在隔离环境中使用演示账号重新展示；原始账号标识、凭据、二维码、聊天和本机路径均未进入截图。首次启动截图来自空数据检查。
